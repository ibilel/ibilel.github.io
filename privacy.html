Privacy policy

Last updated: 29 October 2026

"nycto" is a private publishing tool used only by the owner of the Nycto Gnosis channel to upload and schedule the channel's own videos. It runs on the owner's computer. It is not offered to other people.

YouTube API Services

nycto uses the YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What data it uses

When the channel owner signs in with Google, nycto receives an access token for the owner's YouTube channel. It uses it only to upload videos, set their title, description, thumbnail, captions and publish time, and read the channel's name to show which channel is connected.

Where it is stored

The token and the channel name are stored only on the owner's computer. nycto has no server and sends this data to no one other than Google. It does not collect, sell or share any data about viewers or other users.

Removing access

Access can be removed at any time on the Google security settings page. Deleting the token file on the owner's computer also removes it from nycto. nycto keeps no copy of any YouTube data beyond the channel name and the IDs of the videos it uploaded.
